P2 — Same-origin sandboxed iframe: shared or broken cookie jar

srcdoc iframes inherit the embedder origin (like Code OSS webviews share the webview origin on web). A sandbox without allow-same-origin gets an OPAQUE origin: isolated — but also no cookies, no storage, no session at all. There is no per-pane real browser session in between.
